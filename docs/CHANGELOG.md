# 更新日志

## v6.0.0

### 通用外部单词本适配

- 浏览器扩展与 VS Code 插件新增可关闭的外部单词本适配，仅记录英文单词，支持查词后自动收藏和查词结果中的手动收藏；VS Code 单词本设置独立归类为 `AI Translate Hover: Vocabulary`。
- 支持配置 API 地址、GET/POST、JSON 请求头、请求体或 GET 参数模板，以及 Bearer/Basic 认证；模板可引用单词、释义和英美音标，GET 模板必须为 JSON 对象。
- 单词本请求与查词结果解耦，外部接口异常不会影响查词、翻译或发音。
- 浏览器扩展的请求日志新增 `vocabulary` 类型，展示 HTTP 状态码并对认证类请求头进行脱敏展示；配置解析失败同样记录错误日志。

## v5.0.1

### 稳定性与项目说明页

- VS Code 悬停请求的取消令牌贯穿有道词典、内置翻译和 OpenAI 兼容接口；鼠标移开后，已发出的请求会立即取消。
- VS Code 译文缓存限制为 500 条、有效期 6 小时；词典缓存限制为 1000 条、有效期 24 小时，并按最近使用项淘汰。
- GitHub Pages 从单独支持页调整为项目功能说明页，包含浏览器扩展、VS Code 插件、安装与页面内项目支持区；独立支持服务保留为备用入口。

## v5.0.0

### 双插件发布

- 项目发布面明确包含浏览器扩展和 VS Code 扩展；每次发布必须同时构建三种浏览器 zip 与 VSIX。
- 浏览器扩展发布版本提升至 `5.0.0`，覆盖 Chrome、Edge 与 Firefox。
- VS Code 扩展首次以同一主版本 `5.0.0` 交付。

### VS Code Skill 文档阅读辅助

- 面向中文用户阅读英文 Skill 文档的场景，支持选中英文单词或连续中文词语后悬停查询。
- 内置有道移动翻译与词典优先级，无需 API Key；服务不可用时回退到配置的 OpenAI 兼容接口。
- 英文单词展示英式/美式音标、英美发音入口、中文释义和英文释义；移除重复翻译区。
- 发音使用 VS Code 内复用的播放器面板，不再打开外部浏览器；切换单词时更新到最新音频。
- 自动将 `https://dict.youdao.com` 加入 VS Code 受信任域名列表，避免发音链接确认提示。
- 支持 `hover`、`keyboard`、`hoverAndKeyboard` 三种触发方式；不预设快捷键，用户可在 VS Code Keyboard Shortcuts 中绑定命令。
- 快捷键触发使用与悬停相同的 Hover 词典弹框；支持在选区边缘触发，减少鼠标定位误差。
- 增加 OpenAI 兼容接口、内置有道接口、超时与词典 HTML 解析的自动化测试。

## v3.0.0

### Release

- 将当前工作区改动整理为 v3.0.0 发布版本。
- 修复 Firefox MV2 发布包后台脚本中的 `importScripts` 兼容问题。
- 修复构建脚本刷新 zip 和静态 HTML/CSS 同步逻辑。
- Edge/Chrome 增加发音后备能力：Web Speech 优先，后台 `chrome.tts` 兜底。
- 配置页新增“弹框语言”，支持只对英文、中文、日文或韩文内容弹框。
- 新增 Edge Add-ons 商店素材生成脚本和图片资源。

### 交互与配置页优化

- 划词弹框触发条件调整为“选中文本 + Ctrl”，两者缺一不可；支持先选中文本后按 Ctrl 触发。
- 配置页改为左侧菜单、右侧详情布局：
  - 左侧上部管理多个大模型配置。
  - 左侧下部提供“全局设置”入口。
  - 右侧按当前选择显示模型详情或全局设置详情。
- “翻译方向 / 原文语言 / 译文语言”迁移为全局设置，所有大模型共享。
- 大模型配置只保留接口、模型、温度、超时、优先级、提示词和 JSON 配置等模型相关内容。
- 优化配置页和网页弹框视觉层级，统一焦点态、卡片状态、日志列表和弹框工具栏样式。

### 弹框语言过滤修复

- 修复内容脚本刷新后未正确读取 `settings.popupLanguage` 的问题。
  - 原因：`loadSettings()` 曾在 `browserApi` 初始化前执行，刷新页面时会回退到默认 `all`。
  - 处理：提前初始化 `browserApi`，确保刷新后读取已保存配置。
- 设置 `English` 时，中文、中文夹英文、日文和韩文内容不会触发弹框。
- 语言不匹配时会隐藏弹框，并清空查词输入框、原文、译文、词典区域和错误状态，避免旧内容残留。

### 日志策略

- 请求日志最多保留最近 20 条。
- 配置页前台日志列表只展示最新 10 条。
- 超出 20 条的历史日志按先进先出策略自动丢弃。

## v2.0.1

### 功能优化

1. **并行请求优化**
   - 划词翻译英文单词时，翻译请求和词典查询并行发送
   - 减少用户等待时间，约节省一半时间

2. **自定义模型选项**
   - 已部署模型下拉框新增"自定义模型..."选项
   - 选择后可手动输入模型名称并保存
   - 不会在获取模型列表后被清除

3. **删除模型保护**
   - 删除模型时检查启用的模型数量
   - 如果只剩一个启用的模型，弹框提示"至少需要保留一个启用的模型配置"

4. **请求日志优化**
   - 日志保留条数从 50 条减少到 15 条
   - 清空日志时弹框确认

### 配置页布局

调整后的顺序：
1. 接口预设
2. 模型接口（包含温度、超时，已部署模型含自定义选项）
3. 翻译参数
4. 前端交互
5. 提示词
6. 模型配置文本
