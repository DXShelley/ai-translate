TRANSLATION, WHERE YOU READ

在网页与编辑器中，直接理解原文。

AI Translate 同时提供浏览器扩展和 VS Code 插件：前者处理网页划词，后者帮助中文用户阅读英文 Skill 文档。

当前发布版本 v5.0.1

WEBCODE

两种使用场景

浏览器扩展

为网页阅读提供划词、句子和段落翻译。支持本地或 OpenAI 兼容模型、多模型优先级回退，以及中英自动方向判断。

VS Code 插件

在编辑器内选择单词后查询词典。适合阅读英文 Skill 文档时查看音标、英美发音和中英文释义。

01

浏览器扩展

网页阅读的翻译工具链

  • 划词、句子、段落三种翻译粒度。
  • OpenAI 兼容接口、多模型优先级与失败回退。
  • 英文词典、历史记录、右键菜单与快捷键入口。
  • Chrome、Edge、Firefox 三种发布包。
查看浏览器扩展说明
02

VS Code 插件

为英文 Skill 文档设计的选词词典

  • 选中英文单词或连续中文词语后，以悬停弹框呈现结果。
  • 优先使用内置有道词典与翻译，必要时回退到 OpenAI 兼容接口。
  • 展示英式/美式音标、英美发音入口、中文释义与英文释义。
  • 支持悬停、快捷键或组合触发；快捷键由用户自行绑定。
查看 VS Code 插件说明

安装与发布

从同一个 Release 获取全部交付物

浏览器

下载 Chrome、Edge 或 Firefox 对应 zip，解压后在浏览器扩展管理页加载。

VS Code

下载 `.vsix`，在 Extensions 菜单中选择 Install from VSIX...。

打开最新发布
